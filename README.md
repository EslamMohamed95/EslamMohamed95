## 👨‍💻 About me

I started out in **Mechatronics & Robotics Engineering at Ain Shams University**, where I learned to love systems where hardware, software and math have to work together. That mindset never left: today I'm a **Software Engineer with 4+ years of experience**, building backend systems the same way I'd build a robot — **structured, reliable, and made to run under real-world pressure.**

- 🚀 Currently a **Software Engineer Specialist** improving performance and security of production systems with **Java & Spring Boot**
- 🔧 I design scalable, event-driven services with **Kafka, MySQL and MongoDB**
- 🧠 I've trained and shipped **machine learning models**, from predictive models to **object detection**
- 🏥 Lately I'm working on **lab integration**: connecting analyzers to LIS systems through gateways
- 🤖 I'm fascinated by **AI-assisted engineering**: agents, MCP, and workflows that make developers faster
